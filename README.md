# Markdown Studio ✍️

A simple Markdown editor that turns plain text into HTML and lets you see the results as you type.

I built this project to practice my JavaScript skills and explore how regular expressions can be used to convert Markdown syntax into HTML. I also wanted to give it a clean, modern interface that makes writing and testing Markdown enjoyable.

## ✨ What can it do?

- **Live preview:** See your Markdown formatted instantly as you type.
- **HTML output:** View the HTML generated from your Markdown.
- **Text formatting:** Supports headings, bold, italic, and strikethrough text.
- **Links and images:** Turn Markdown links and image syntax into HTML elements.
- **Lists and quotes:** Supports ordered lists, bullet points, task lists, and blockquotes.
- **Code blocks:** Display inline code and fenced code blocks.
- **Markdown tables:** Organize information into simple tables.
- **Copy HTML:** Copy the generated HTML to use in another project.
- **Editor statistics:** Keep track of your characters, words, and lines.
- **Responsive design:** Use the editor on desktop and smaller screens.
- **Clear editor:** Start fresh whenever you want.

## 🛠️ Built with

- HTML5 — for the page structure.
- CSS3 — for the layout, styling, and responsive design.
- JavaScript — for Markdown conversion and interactive features.
- Regular expressions — for recognizing and converting Markdown syntax.

No frameworks are required. The project runs directly in your browser.

## 🚀 Getting started

Want to try it on your computer?

1. Clone this repository or download the project files.
2. Open the project folder in VS Code.
3. Open `index.html` using the Live Server extension.
4. Start typing Markdown in the editor.
5. Watch the generated HTML and live preview update automatically.

You can also open `index.html` directly in a modern browser.
